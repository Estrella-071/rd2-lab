# Support

Start with [README.md](README.md), [site/README.md](site/README.md), and [REPRODUCING.md](REPRODUCING.md).

- Website operation or browser issue: use the bug template with the URL, commit, device, browser version, and steps.
- Data issue: use the data correction template with the affected version, ID, current value, proposed value, and evidence.
- Feature idea: describe the user scenario, desired result, and verification path.
- Security issue: follow [SECURITY.md](SECURITY.md) and use the private contact address.
